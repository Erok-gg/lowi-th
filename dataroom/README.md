# LOWI — Data room

Welcome. This room holds the documents behind the LOWI investor dossier: the
numbers, the method that produces them, and the structure that holds the assets.
It is organised so that every claim in the dossier can be traced to a file here.

## How to read it

1. **Start with the documents marked ★ Key document.** They are the shortest path
   to the substance — in particular the methodology note that explains the
   maths of the platform.
2. **Then go folder by folder**, in the order of the left-hand menu.
3. **Every figure carries its nature.** We distinguish what is *measured*
   (reproducible from the platform database), what is *inferred* (stated
   reasoning), and what is a *projection* (a modelled assumption). A projection
   is never presented as a measurement.

## Folders

| Folder | What you will find |
|---|---|
| Start here | This read-me and the documents to open first. |
| Pitch & dossier | The investor dossier and the slide deck, as PDFs. |
| Methodology & maths | How the platform collects listings, compares units within the same building, and computes yields and discounts. |
| Financial model | The return decomposition behind the 8–10 % target IRR, scenario by scenario. |
| Legal & structure | Holding structure, escrow, foreign-quota ownership, tax on exit. |
| Deal pipeline | Case studies of screened properties — including the ones we walked away from. |
| Platform & data | Coverage, sources, data quality and known limits. |

## Confidentiality

Documents are shared for your evaluation only. Each PDF is watermarked with
your name and the time you opened it, and each consultation is logged. Please
do not forward your sign-in link; ask us to invite a colleague instead.
